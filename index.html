المتطابقات الشهيرة

نشر وتبسيط العبارات الجبرية

السنة الرابعة متوسط

تعلم كيف تحول عبارة جبرية إلى شكل مبسط بسرعة ودقة.

ما هي المتطابقة الشهيرة؟

هي قاعدة جبرية تساعدنا على نشر وتبسيط بعض العبارات بسرعة.

بدل القيام بتوزيع طويل، نستعمل قاعدة جاهزة.

(a + b)²

يمكن تحويلها مباشرة إلى عبارة مبسطة.

القواعد الثلاث الأساسية

الأولى

(a + b)²

مربع مجموع

الثانية

(a - b)²

مربع فرق

الثالثة

(a+b)(a-b)

جداء مجموع وفرق

المتطابقة الأولى

مربع مجموع

(a + b)² = a² + 2ab + b²

قاعدة الحفظ:

مربع الأول + ضعف الأول × الثاني + مربع الثاني

مثال

(x + 3)²
= x² + 2(x)(3) + 3²
= x² + 6x + 9

المتطابقة الثانية

مربع فرق

(a - b)² = a² - 2ab + b²

لاحظ أن الإشارة السالبة تكون أمام الحد الأوسط فقط.

مثال

(x - 4)²
= x² - 2(x)(4) + 4²
= x² - 8x + 16

المتطابقة الثالثة

جداء مجموع وفرق

(a + b)(a - b) = a² - b²

الحد الأوسط يختفي.

مثال

(x + 6)(x - 6)
= x² - 6²
= x² - 36

كيف أميز بين المتطابقات؟

①

(a+b)²

نجد قوسًا واحدًا مرفوعًا للقوة 2.

②

(a-b)²

قوس واحد وفيه طرح.

③

(a+b)(a-b)

قوسان: مجموع وفرق.

مثال تطبيقي

انشر وبسط:

(2x + 5)²
= (2x)² + 2(2x)(5) + 5²
= 4x² + 20x + 25

تذكر: لا تنسَ تربيع العدد الموجود أمام x.

تمرين 1

ما هو نشر:

(x - 5)²

تمرين 2

ما هو نشر:

(x + 7)²

تمرين 3

بسط:

(x + 8)(x - 8)

الخلاصة

مربع مجموع

(a+b)²=a²+2ab+b²

مربع فرق

(a-b)²=a²-2ab+b²

مجموع وفرق

(a+b)(a-b)=a²-b²

أحسنت! الآن حاول تطبيق القواعد على تمارين مختلفة.
